# 演示脚本（上板跑一遍，照着念/照着做）

> 目标：3~5 分钟内让评委看清「TF 卡里的照片 → FPGA → HDMI 显示 + 数码管 + 按键交互 + 音频」。
> 现场最容易翻车的三个点：**HDMI 丢锁**、**卡没插好**、**烧录线/供电接触不良** —— 都写了应对。

---

## 0. 上台前 10 分钟准备

| 项 | 检查 |
|---|---|
| 电源 | DC 电源插到底，开关拨到位；板上电源灯**常亮不闪** |
| HDMI | 线插紧（两头都按一下）；显示器输入源选 **HDMI** |
| TF 卡 | 提前插好（**不支持热插拔**）；用读卡器确认根目录只有 `IMG0001.BMP…`（8.3 名字、FAT32） |
| 下载 | AL-LINK 的 USB 直插笔记本（别走扩展坞）+ 10 针排线红线对 1 脚 |
| 耳机 | 3.5 mm 插到底（M4 才需要） |
| 备用 | 另一张已格式化好的卡、另一根 HDMI 线、另一个 USB 口 |

**建议**：上台前把最终 bit **固化到 Flash**（若已验证）或至少**提前烧好并确认出图**。
SRAM 配置掉电即失，现场重烧会强制"HDMI 丢锁"。

## 1. 开场（30 秒）

> "这是基于安路 EG4S20 的 HDMI 多媒体播放器。FPGA 片内 8 MB SDRAM 做双缓冲帧缓存，
> TF 卡以 SPI 模式读 FAT32 文件系统里的 BMP 图片，FPGA 直接输出 1280×720 TMDS 到显示器，
> 按键换图、数码管显示序号，M4 还带 WM8960 音频输出。"

先让屏幕停在已出图的画面上 —— 不要一上来就烧录。

---

## 2. 主流程

| # | 动作 | 期望现象 | 如果不对 |
|---|---|---|---|
| 1 | 板上电（已烧好 bit） | 约 1 秒后中央出现照片（四周黑边，1:1 显示） | 屏显 no signal → **拔插 HDMI 线**；仍不行 → 看 LED |
| 2 | 按 **S0**（短按） | 立刻切到下一张，数码管低 4 位 +1 | 无反应 → 等当前页加载完（约 1.5 s）再按 |
| 3 | 按 **S1**（短按） | 切到上一张 | —— |
| 4 | **长按 S0 ≥ 1 秒** | 轮播暂停，数码管小数点闪烁 | 短按才换图，长按才是暂停 |
| 5 | 再长按 1 秒 | 轮播继续（每约 3 秒自动进一张） | —— |
| 6 | 拔掉 TF 卡，按 **S2** 复位 | 约 2.7 秒后中央出现**绿色边框 + 红绿渐变**测试图案 | 若还是照片 → 卡没拔到底 |
| 7 | 插回 TF 卡，按 **S2** | 回到照片 | 卡必须插到底（听到"咔"） |
| 8 | （M4）戴耳机 | 能听到 1 kHz 提示音 | 无声 → 查耳机口/音量；数码管 D3 位可看音频初始化结果 |

### 数码管读数方式

```
digit 7 6 5 4 3 2 1 0
      [总数]  .  [当前序号]
  "  0  5  -- 0 0 0 2  "  → 共 5 张，正在显示第 2 张
  出错时显示 "E<n>"，n 是错误码（见 docs/research/bench-bringup-postmortem.md §4）
```

### LED 读数方式（低电平点亮，亮 = 该位为 0）

```
led[3] 页号 | led[2] 有错误 | led[1] 正在写 | led[0] 卡已挂载
```

正常出图时：`led0` 亮（卡 OK）、`led1` 灭、`led2` 亮（无错误）。

## 3. 现场排障（按顺序，30 秒内定位）

| 现象 | 先做什么 | 再看什么 |
|---|---|---|
| 全黑 / no signal | **拔插 HDMI 线** | 换 HDMI 线、确认显示器输入源 |
| 有信号但全黑 | 按 S2 复位 | LED：`busy` 常亮 → SDRAM 写入卡住（不太会发生，已修） |
| 中央是渐变图案 | 卡没读出来 | 数码管 `E<n>`：1=没插好 2=不是 FAT32 3=没找到 IMG 文件 4=BMP 头不对 |
| 照片是黑的/只有一部分 | 卡的 BMP 不是 640×480 24 bit | 用 `tools/make_bmp.py` 重新生成 |
| 按键无反应 | 等当前页加载完 | 长按/短按区别：短按=换图，长按 1 s=暂停 |
| 灯全灭 | 供电掉了或 bit 没配上 | 电源灯；重新烧录 |

> **一句话兜底**：现场任何"没画面"，第一步永远是**拔插 HDMI 线**，第二步是**按 S2**。
> 这两步能解决 90% 的现场问题，且不需要电脑。

## 4. 录演示视频要点（交稿用）

1. **画面要有整个显示器 + 板子同框**，能看出 HDMI 线连到板子、板上 LED 状态；
2. 依次拍到：出图 → 按 S0 换图（两次）→ 长按 S0 暂停（拍到小数点闪）→ 再次长按恢复 → 拔卡复位出测试图案 → 插卡出图；
3. M4 单独拍一段：耳机插上 + 拍到数码管 + 说明"1 kHz 正弦，48 kHz 采样，I2S 主机，WM8960 解码"；
4. 旁白逐条说明"这是 FPGA 内部哪个模块在做"（帧缓存、FAT32、TMDS、I2S），别只拍现象；
5. 时长控制在 3 分钟内，最后 10 秒给板卡/工具链特写（TD 版本、bit 文件名）。

## 6. M5 演示：视频 + 声音（历史里程碑，`proj/m5_video`；交付版见 §7）

> 从 M5 开始播放器直接播 **TF 卡里的视频文件**：画面来自 M5V1 软解码，
> 声音走 **HDMI 内嵌音频**从**显示器自带喇叭**出声（不再需要耳机）。

### 6.1 上台前准备

| 项 | 检查 |
|---|---|
| TF 卡 | FAT32，根目录放 `VID0.M5V`（本仓库 `out/VID0.M5V`，7.4 MB） |
| 显示器 | 输入源选 **HDMI**；**SPK 开关拨到开**；音量调到 60% 以上 |
| HDMI | 两头插到底（每次重烧 bit 后都要**拔插一次**重新锁屏） |
| 供电 | DC 插到底，电源灯常亮 |
| 烧写 | `tools\flash.ps1 -Proj m5_video`（SRAM 配置，断电即失） |

### 6.2 主流程（约 1 分钟）

| # | 动作 | 期望现象 | 如果不对 |
|---|---|---|---|
| 1 | 插卡上电（已烧好 bit） | 约 2 秒后屏幕出现 720p 画面：白桌上一张动漫人物照片，**连续播放**（15 fps） | 屏显 no signal → **拔插 HDMI 线** |
| 2 | 听显示器喇叭 | 出 **视频原声**（音乐/人声），与画面同步 | 无声 → 先查 **SPK 开关/音量**；再看 LED |
| 3 | 等待 19 秒 | 286 帧播完自动回到第 1 帧循环 | 不循环 → 卡问题或 `E<n>` |
| 4 | 读数码管 | 低两位 = 当前帧序号（模 32 循环），出错显示 `E<n>` | 见 6.3 |

### 6.3 LED 与错误码（低有效：亮 = 条件成立）

```
D4 = HDMI 音频样点在流动      D3 = 正在解码/写帧（播放时闪）
D2 = 有错误                   D1 = TF 卡挂载成功
```

| 数码管 | 含义 |
|---|---|
| `E1` | 不是 M5V1 / bpp 不是 RGB332 |
| `E2` | RLE 行数不对（数据损坏，仅告警） |
| `E4` | 帧块头长度非法 → 正在重新同步 |
| `E5` | 帧内找不到结束符 |
| `E6` | 音频样点数异常 |
| （E0 无错误） | 正常播放 |

卡/文件类错误由 streamer 报告：`E1` 卡初始化、`E2` BPB、`E3` 根目录、`E4` 找不到 `VID0.M5V`、`E5` 扇区读、`E6` FAT 读。

### 6.4 录演示视频要点（M5）

1. **显示器 + 板子同框**，能看清 HDMI 线、板上 LED（D1 亮、D3 闪、D4 亮）；
2. 拍到：出画面 → 声音（录进原声）→ 循环回到开头；
3. 旁白要点："TF 卡 FAT32 线性扇区流 → FPGA 内 M5V1 RLE 软解码 → 片内 8 MB SDRAM 双页 →
   1280×720 TMDS；每帧 3200 个 48 kHz 样点经异步 FIFO 送入 HDMI 音频包（LPCM 24 bit + ACR
   时钟再生），由显示器喇叭出声"；
4. 结尾给板卡/TD 版本/bit 名特写。

## 7. M6 演示：图文混排播放列表（**当前交付版本**，`proj/m6_media`）

> M6 把 M3 的**照片**和 M5 的**视频**放进**同一个播放列表**：上电后自动顺序播放
> （照片 3 s 一张 → 视频连播带声音 → 回到第一张循环），按键/长按规则与 M3 完全一致。
> 视频声音仍走 **HDMI 内嵌音频**（显示器自带喇叭）。

### 7.1 上台前准备

| 项 | 检查 |
|---|---|
| TF 卡 | FAT32；根目录：`IMG0001.BMP … IMG0005.BMP` + `VID0.M5V` / `VID0005.M5V` / `VID0006.M5V`（本仓库 `out\VID0005.M5V`、`out\VID0006.M5V`，也可从 `E:\fpga-2026\m6_card\` 取） |
| 显示器 | 输入源选 **HDMI**；**SPK 开关拨到开**；音量 60 % 以上（便携 7 寸屏的 SPK 是物理开关） |
| HDMI | 两头插到底；**每次重新烧 bit 后必须拔插一次**才能重新锁屏 |
| 烧写 | 已固化：`tools\flash.ps1 -Proj m6_media -Mode program_spi`（断电重启仍然生效）；临时调试用不带 `-Mode` 的版本（SRAM，断电即丢） |
| 数码管 | 左 4 位 = 列表总条数，右 4 位 = 正在播第几条（1 起）；出错显示 `E<n>` |

### 7.2 主流程（约 90 秒，正好一遍列表）

| # | 动作 | 期望现象 | 如果不对 |
|---|---|---|---|
| 1 | 插卡上电（无需下载器） | 约 2 s 后中央出现第 1 张照片，数码管 `0008    0001` | 屏显 no signal → **拔插 HDMI 线** |
| 2 | 等 ~12 s | 每 3 s 自动换一张，序号 0002→0005 | 不动 → 是否按过长按（暂停，两端小数点亮） |
| 3 | 等第 5 张播完 | 进入第 1 段视频，**有原声**，画面 15 fps 流畅 | 无声 → 先查 SPK 开关/音量；黑屏 → 看 `E<n>` |
| 4 | 等 ~38 s | 第 1 段播完自动进第 2 段，再进第 3 段 | 卡在某段 → 看 `E<n>` / LED |
| 5 | 等第 3 段播完 | 回到第 1 张照片（列表循环） | 不循环 → 卡问题 |
| 6 | 短按 `S0` / `S1` | 立刻下一条 / 上一条（视频也能被切到） | 无反应 → 按一下 S2 复位再来 |
| 7 | 长按 `S0` 1 s | 暂停（两端小数点点亮）；再长按恢复。暂停中短按 `S0` 可逐项浏览，视频会播放、播完停住 | — |
| 8 | 拔卡按 S2 | 中央出现绿框+渐变测试图案，数码管 `E3` | 若还是照片 → 卡没拔到底 |

### 7.3 LED 与错误码（低有效：亮 = 条件成立）

```
D4 = 正在播视频（HDMI 音频在流动）     D3 = 正在装图/解码（播放时闪）
D2 = 有错误                            D1 = TF 卡挂载成功、播放列表已建立
```

| 数码管 | 含义 |
|---|---|
| `E1` | 卡初始化失败（没插好 / 不是 SPI 模式） |
| `E2` | 不是 FAT32 / BPB 字段不合法 |
| `E3` | 根目录里没有 `IMGnnnn.BMP` / `VIDnnnn.M5V` |
| `E4` | BMP 头不对（不是 640×480 24 bit），或视频文件头/帧块头非法 |
| `E5` | MBR 的 0x55AA 签名不对（扇区数据是坏的） |
| `E6` | 图片文件比 640×480 需要的还小 |
| `E7` | 分区表里没有可接受的分区项 |

### 7.4 录演示视频要点（M6）

1. 画面里同时有**显示器、板卡、数码管**，能看清 HDMI 线；
2. 依次拍到：自启动出图 → 自动换图（数码管序号递增）→ 切进视频（**录进原声**）→
   短按 S0 切到下一段 → 长按 S0 暂停（小数点亮）→ 暂停中短按逐项浏览（切到视频）→ 恢复播放 → 循环回第 1 张；
3. 旁白要点："一次目录扫描把 BMP 和 M5V 混排成一个列表；照片走 M3 的逐行写页，视频走 M5 的
   RLE 软解码 + SDRAM 双页环形写，两个引擎互斥占用同一套 SD 引擎；声音是 48 kHz 单声道经异步 FIFO
   进 HDMI 音频包（LPCM 24 bit + ACR），由显示器喇叭出声；bit 已固化在 SPI 配置 Flash 里，上电自启动"；
4. 结尾给板卡 / TD 版本 / bit 名 / 数码管读数特写。
