# 选题一 · 基础功能设计（HDMI 图片播放器）

- 日期：2026-10-21
- 状态：**待用户评审**（评审通过后进入实现）
- 依据：`docs/research/hw-facts.md`、`docs/research/example-arch.md`、`docs/research/td-toolchain.md`、官方《2026 FPGA 赛道选题指南（安路）》`docs/research/anlogic_2026_guide.pdf`

## 1. 目标（基础功能）

按官方样例 lab_ex_4 / lab_ex_5 的规格，在 **AC208 板（EG4S20BG256，TD 2026.1 SP2）** 上实现：

1. 从 TF 卡读取 640×480 24-bit BMP 图片（FAT32 根目录自动扫描）
2. 读入片内 SDRAM 帧缓存（A/B 两页，双缓冲）
3. HDMI 640×480 输出显示
4. 按键手动切图 + 自动轮播 + 暂停
5. 基础音频输出（正弦测试音 → WM8960 → 耳机/喇叭）
6. 数码管显示当前图片编号

**不做**（留给扩展项）：JPEG 解码、音画同步、转场特效、HDMI 音频、缩放、OSD 字幕。

## 2. 系统框图

```
TF 卡 ──SPI──> SD 扇区引擎 ──> FAT32-lite ──> BMP 解析 ──> 像素打包(32bit/px)
                                                                    │
                                                          ┌─────────▼─────────┐
                                                          │ 片内 8MB SDRAM      │
                                                          │ 页A(0x000000)       │
                                                          │ 页B(0x12C000)       │
                                                          └─────────┬─────────┘
                                                                    │ RD1
                                                            AXIS 视频源
                                                                    │
                                                     HDMI 1.4b 发射核（加密IP）+ TMDS
                                                                    │
                                                             640×480@~59.5Hz

按键(3) ──> 控制FSM ──> 页选择 / 切图 / 轮播 / 暂停 ──> 数码管(图号)
音频：正弦ROM ──> I2S TX ──> WM8960 ──> 耳机口
```

## 3. 时钟与复位

| 时钟 | 频率 | 来源 | 用途 |
|---|---|---|---|
| `clk_50m` | 50 MHz (K14) | 板载晶振 | PLL 参考 |
| `pix_clk` | 25.0 MHz | PLL1 | 像素时钟（640×480@59.5Hz） |
| `ser_clk` | 125.0 MHz | PLL1（与 pix 同相位/90°） | TMDS 串行时钟（10:1） |
| `sys_clk` | 100 MHz | Sdram_Control_4Port 的 `CLK` 输出 | SD 卡/状态机/写控制 |
| `aud_mclk` | 12.288 MHz | PLL3 | WM8960 MCLK（48kHz×256） |

- PLL 共 4 个：PLL1(HDMI 双输出) + SDRAM 控制器内部 PLL + PLL3(音频)，余 1 个。TD 的 PLL 支持小数分频（板测例程就有 23.81 MHz / 8.197 MHz），12.288 MHz 可实现。
- 复位：低有效，`rst_n` 用 KEY2(H14) + PLL lock 同步。
- **必须写 SDC**：`create_clock` 25MHz/125MHz（二者 exclusive）/100MHz/12.288MHz，不要沿用例程里按内部网名写的旧约束。

## 4. SDRAM 帧缓存与地址映射

- 控制器：`Sdram_Control_4Port` + `EG_PHY_SDRAM_2M_32`（片内 2M×32 = 8 MB）。
- 像素格式：**32 bit/像素**（RGB888 存低 24 位，高 8 位留空），640×480 = 307,200 字 = 1,228,800 B ≈ 0x12C000。
- 页 A：`0x000000`；页 B：`0x12C000`。两页合计 2.4 MB，8 MB 内余量充足。
- 写：WR1 端口，地址 = 页基址，`WR1_LOAD` 在开始写一页时脉冲一次；写完整页后切换显示页。
- 读：RD1 端口，显示侧按行顺序读，`RD1_LOAD` 在换页时脉冲。
- 换页在**场消隐期间**完成，避免撕裂。

## 5. HDMI 输出

- 复用 board_test 的加密 IP：`hdmi_1_4b_transmitter_core_wrapper.enc.v` + `hdmi_phy_warpper.v` + `lane_lvds_10_1.v`（TD 可直接编译，无需额外 license）。
- 参数改为 640×480@60 时序：`HTOTAL=800, HSA=96, HBP=48, HFP=16, HACTIVE=640; VTOTAL=525, VSA=2, VBP=33, VFP=10; VIC=1; RGB`。
- `VIDEO_TPG = "Disable"`，由 `video_gen` 提供 AXIS 流（`I_axis_s_data[23:0]`, valid/ready）。
- 引脚（AC208）：TMDS CLK B10/C9、D0 D11/D12、D1 C11/A11、D2 F10/H11，`LVDS33_E`。

## 6. 存储与文件层

- **SD 卡 SPI 引擎**：复用 `uart_sd_rw` 的 `sd_card_control` 及其子模块（SPI Mode3，初始化 400 kHz，数据 25 MHz）。改造点：去掉串口命令解析，改成"请求扇区 → FIFO 流出"。
- **FAT32-lite（只读）**：MBR → 分区 BPB → 根目录项线性扫描 → 文件名匹配（`*.BMP`）→ FAT 链 → 扇区序列。不支持长文件名（用 8.3 名，如 `IMG0001.BMP`）、不支持子目录（或只支持根目录）。
- **BMP 解析**：校验 54 字节头（`BM`、biSize=40、biWidth=640、biHeight=480、biBitCount=24、无压缩），处理自底向上行序 + 4 字节行对齐，BGR→RGB。
- 读图速度：640×480×3 = 900 KB，SPI 25 MHz 约 **0.4 s/张**（可接受，切图时显示"加载中"或保持旧图）。

## 7. 控制与交互

- 3 个按键（KEY0 F7 / KEY1 E7 / KEY2 H14 作复位）：切下一张、切上一张、播放/暂停。
- 自动轮播：默认 3 s/张（可用拨码开关调）。
- 数码管（2×74HC595，三线）：显示当前图号/总数/状态。

## 8. 音频（基础）

- WM8960 通过 I2C 初始化（器件地址需实测确认：代码里是 `0x20`，常见 WM8960 为 `0x34`）。
- I2S 发送：48 kHz、16 bit、双声道；MCLK 12.288 MHz。
- 基础版播放**内部正弦测试音**（DDS/ROM），验证 I2C+I2S+codec 全链路；WAV 播放留扩展。
- 引脚以管脚表为准：MCLK B8、BCLK C8、DACLRC A8、DACDAT A7、ADCLRC C7、ADCDAT C6；I2C SCL L16 / SDA M16。

## 9. 工程骨架

**方案 A（推荐）**：复制 `board_test` 工程为起点，删除以太网、OV5640、RTC、红外、蜂鸣器、36 位 GPIO、数码管旧逻辑等无关模块，保留 PLL 与 HDMI 链，然后按模块加入本设计内容。
- 理由：HDMI 加密 IP 的例化、PLL/IP 配置是现成可编译的；从零建工程需要手工生成 IP，风险高。
