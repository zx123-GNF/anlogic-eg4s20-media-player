## 硬性约束（非常重要）

1. **路径必须全英文**：TD 打不开含中文、空格、括号的工程路径（会报 Chinese characters 警告）。所以本仓库名和所有子目录名一律用英文/数字/下划线。
2. `.al` 工程里引用源码尽量用**相对路径**，这样仓库搬到别处也能打开。
3. 只把源码 / 约束 / 文档 / 工程配置提交进 git；`db/`、`*_Runs/`、`*.bit`、日志报表等编译产物由 `.gitignore` 忽略。
4. 烧录用 `.bit` 不进仓库，需要时在本地 `..._Runs/best_result/` 里取。
